# bs (brainstorm)

根据用户提供的主题或想法进行头脑风暴，逐个展示选项供用户选择，最终将选中的内容同步到项目文档。

## 使用方式

用户输入 `/bs` 时触发，后面可跟主题描述。例如：
- `/bs bootstrap下载功能优化`
- `/bs 新增文件管理模块`
- `/bs` （不带参数时，从当前对话上下文推断主题）

## 执行流程

### 第一步：确定主题

- 如果用户在 `/bs` 后提供了主题，使用该主题
- 否则从当前对话上下文中推断讨论的核心主题
- 向用户确认主题是否正确

### 第二步：头脑风暴

围绕主题，从以下维度进行发散思考：
- **功能点**：可以实现哪些具体功能
- **技术方案**：有哪些实现方式可选
- **优化项**：性能、体验、可维护性等方面的改进
- **扩展性**：未来可以扩展的方向
- **风险点**：需要注意的问题和边界情况

生成 5-10 个有价值的选项，每个选项包含：
- 简短标题（一句话概括）
- 具体描述（2-3 句话说明价值和实现思路）

### 第三步：逐个选择

使用 AskUserQuestion 工具展示选项，让用户逐个选择：
- 每次展示 3-4 个选项，用户可选择感兴趣的
- 选中的选项标记为"已选"，继续展示下一批
- 重复直到所有选项都过了一遍
- 用户可以多选（multiSelect: true）

### 第四步：同步到文档

将用户选中的内容同步到文档：
- 确定所属模块名（从主题推断或用户指定）
- 写入 `docs/{模块名}需求.md` 或 `docs/{模块名}接口.md`
- 格式：

```markdown
# {模块名}需求

## 头脑风暴 - {日期}

### {选项标题}

{选项描述}

```

### 第五步：总结

- 显示同步结果
- 列出所有选中的要点
- 询问用户是否基于这些要点开始开发

## 示例

用户：`/bs 下载脚本优化`

Claude 执行：
1. 确认主题："下载脚本优化"
2. 头脑风暴生成选项：
   - 断点续传支持
   - 并发下载提速
   - 下载进度可视化
   - 自动重试机制
   - 代理配置支持
   - ...
3. 逐批展示，用户选择"断点续传"和"并发下载"
4. 同步到 `docs/下载需求.md`
5. 询问是否开始开发
