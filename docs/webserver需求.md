# webserver 模块需求

## 功能概述

用 Rust 重写 `download/hermes-web-ui` 的后端实现，创建一个新的 webserver 模块来替代原有的 Node.js (Koa.js) 后端。新模块将保持相同的 API 接口和功能，同时利用 Rust 的性能优势和内存安全性。

## 技术要求

### Rust 技术栈选择

- **Web 框架**: Actix-web 或 Axum
- **WebSocket**: tokio-tungstenite 或 actix-web-actors
- **数据库**: SQLite (通过 rusqlite 或 sqlx)
- **认证**: JWT (jsonwebtoken crate)
- **序列化**: serde + serde_json
- **异步运行时**: tokio
- **日志**: tracing + tracing-subscriber

### API 兼容性

- 保持与原有 Node.js 后端相同的 RESTful API 端点
- 保持相同的请求/响应格式
- 保持相同的认证机制
- 保持相同的错误码和错误格式

### 数据库兼容性

- 支持 SQLite 数据库
- 保持与原有数据库 schema 兼容
- 支持从 JSON 文件存储迁移
